A one-line joke about office life: the Wi-Fi password lives on a sticky note on the router, locked in a cupboard whose key is in an email you need the Wi-Fi to open. The program validates the 1–200 character single-line gate and writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` with no trailing newline.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
